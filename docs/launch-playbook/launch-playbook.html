The 11 phases

Tap a phase to open it. Each one has the steps, why we chose it, and the trap to avoid.

1 · Decide & hand over

Day 0
  1. Fill the Day-0 list above
  2. Write a short PRD: who, price, flow, what is not in v1
  3. Look at 1–2 competitors and copy the flow, not the look
  4. Start KYC and Meta verification today
Why

KYC and reviews take days. Code takes hours. Start the slow things first.

Trap

The region is permanent for the database and bucket. Pick the one nearest your users.

2 · Repo, cloud, first deploy

Day 1
  1. Repo from the template, then rename-project.sh
  2. Run gcp-bootstrap.sh before the first merge
  3. Set the GitHub secrets + variables it prints
  4. Firebase: phone sign-in, SMS region = India only
  5. Merge → /api/health says 200
Why

Cloud Run scales to zero and bills per use. Deploys use OIDC, so no key can leak.

Trap

Public NEXT_PUBLIC_* values are baked in at build. Change → redeploy. Skip RUNTIME_SERVICE_ACCOUNT and the app runs as project Editor.

3 · Domain & Cloudflare

Day 1–2
  1. Buy domain; DNSSEC off; nameservers → Cloudflare
  2. SSL Full (strict), Always HTTPS
  3. Need name.domain per customer? AAAA * 100:: + a Worker to Cloud Run
  4. Worker: www → apex, fail closed
  5. WAF rule “Block scanners”: .php /wp- /.env /.git //
Why

Cloud Run and Firebase can't do wildcard domains. A Google load balancer costs ~$18/month flat. The Worker is free.

Trap

A bot scan used up the 100k/day Worker limit with zero users. Never challenge all Google Cloud IPs: it blocked Claude, AI search and webhooks.

4 · Brand & design system

Day 1–3
  1. Logo from a script (SVG source), never hand-edited
  2. Export: favicon .ico, icons 192/512, OG 1200×630, avatars
  3. Put colours + fonts in design tokens
  4. Customer output can keep its own look
Why

One token set keeps every screen consistent; a script remakes the whole kit in seconds.

Trap

Google showed a globe until we added favicon.ico + a PNG in a multiple of 48px. One ₹ sign loaded 125 KB of extra fonts.

5 · Email, WhatsApp, socials

Day 2–3
  1. Cloudflare Email Routing: hello@ + support@ → Gmail
  2. Gmail “Send mail as”; one SPF; DMARC p=none
  3. FB Page → Business portfolio → Instagram → WhatsApp Business app
  4. Verify the domain in Meta (TXT record)
  5. Bio link via a short redirect with UTM (/ig)
Why

Every gateway and ad account asks for a domain email. Manual WhatsApp from the app is free and fast to start.

Trap

Gmail send-as fails DMARC (can hit spam) — fix later with Brevo SMTP. Never “Add” the app number in Meta's WhatsApp screen: it leaves the app.

6 · Product, legal pages, admin

Day 2–8
  1. Short form → instant preview of their product
  2. Pay → publish in one server step
  3. Legal: About, Contact, Terms, Privacy, Refund, Delivery + visible price
  4. /admin: Google + OTP, audit log, never linked
  5. Admin tools: lead tags, “make live”, coupons, content editing
Why

Seeing their own names sold far better than a sample. Gateways reject a site with no policy pages.

Trap

Uploads need bucket CORS. A Strict admin cookie signed you out from Telegram links — use Lax. iPhone date inputs need a custom look.

7 · Payments & KYC

Day 1–9
  1. Apply to Razorpay and Cashfree the same day
  2. Keys go in Secret Manager — never in chat
  3. Server sets the price; server re-checks the payment with the gateway
  4. Webhook too, so a closed tab still goes live
  5. Test with your own UPI on live keys, then refund
Why

Cashfree's link API needed an extra approval that never came. Razorpay passed in a day. One switch (PAYMENT_PROVIDER) picks the gateway.

Trap

KYC name must match PAN, bank and domain invoice. Aadhaar in another state? Udyam gives a free address proof.

8 · Alerts & operations

Day 4–8
  1. Telegram: new lead + payment, with a ready WhatsApp message
  2. Copy-ready follow-ups + a sales call script
  3. Tag leads by hand: New / Hot / Cold / Test
  4. Min instances 0 → 1 only when cold starts hurt
Why

A reply within an hour wins the sale. Telegram is free and instant.

Trap

Three messages shared one timeout, so the important ones got lost. Give each its own timeout + one retry.

9 · Tracking, SEO, AI search

Day 5–9
  1. Own visit beacon (no cookie) → funnel in /admin
  2. Google tag: “Preview made” + “Purchase” only
  3. Meta Pixel: only Lead + Purchase, no PageView
  4. Sitemap, schema, llms.txt, Search Console
  5. Ads land on a page that is the form
Why

Privacy-first means no cookie banner and an honest privacy page. AI assistants repeat only what your pages say.

Trap

ChatGPT said we had no dashboard because no page named it. Add each new feature to the feature list + llms.txt.

10 · First sale, organic, ads

Day 9+
  1. No ad money before one real payment works
  2. Message 30–50 people one by one; founding offer for a review
  3. Instagram: 7 tips : 2 soft : 1 pitch; boost only winners
  4. Meta: Leads objective, 3–5 creatives, check every lead
  5. Write the stop-loss before you spend
Why

Warm contacts and Reels are free tests. Ads should only scale what already works.

Trap

Google Search at ₹6–15 CPC got 0 impressions. A price-comparison ad pulled in other businesses, not customers.

11 · Measure & improve

Ongoing
  1. Weekly: visits → leads → previews → paid, by source
  2. Fix the biggest drop first
  3. Pay step wins: price on the button, reviews, “share with family”, trust line
  4. Every decision → an ADR; every fact → project memory
Why

130 visits → 39 previews → 1 paid showed the leak was the pay step, not traffic.

Traps we already fell into

Read these once. Each one cost us hours or money.

Worker sent traffic to another site

A path starting with // made new URL(path, ORIGIN) fetch a different host.

Build the URL as ORIGIN + path

Free Worker limit gone on day 5

~150k bot requests for .env, .git, .php. No limit left = site down.

Scanner WAF rule; watch the graph

We blocked Claude and AI search

A “challenge Google Cloud” rule caught agents, AI crawlers and could catch webhooks.

Block paths, not whole clouds

Payment link API never switched on

Cashfree needed a second approval after KYC. Days lost.

Apply to two gateways at once

KYC address mismatch

ID showed one state, business ran in another.

Udyam registration (free, same day)

Domain in the wrong name

Gateway asked for the domain invoice in the account holder's name.

Buy the domain as the KYC holder

Secret pasted in chat

A key was sent in a message.

Rotate at once; Secret Manager only

Uploads failed in admin

The bucket had no CORS for our domain.

Keep CORS in a file; a human applies it

Admin signed out on iPhone

Strict cookie + tapping a Telegram link = fresh sign-in.

SameSite=Lax, 90-day sliding session

Lost sale alerts

One shared 4-second timeout for three messages.

Own timeout + retry per message

Mail in spam

Gmail “send as” has no DKIM for our domain, so DMARC fails.

SMTP that signs (Brevo); keep p=none

Search showed a globe icon

Only an SVG icon existed.

favicon.ico + PNG in 48px steps

Zero ad impressions

Google Search with a ₹6, then ₹15 max CPC never showed.

Realistic bids, or skip niche Search

Ads attracted vendors

A price-comparison creative brought other businesses.

Check leads by hand; pause that ad

“Server Action unavailable”

An admin tab opened before a deploy.

Reload; make the error say so

Wrong redirect host

Inside Cloud Run the URL is 0.0.0.0:8080.

Relative redirects behind a proxy

Deploy timed out

9 Firestore index exemptions at ~6 min each.

Skip existing ones; send async

An ad promised an old policy

“7-day refund” stayed in copy after the policy changed.

Re-check claims when policy changes

What it costs

Pay-per-use first. Add a fixed fee only when it clearly pays for itself.

₹0 at launch

  • Cloud Run, Firestore, Storage (scale to zero)
  • Cloudflare Free: DNS, SSL, Email Routing
  • Firebase phone OTP (pay per SMS — lock to India)
  • Telegram alerts, WhatsApp app

Small, when needed

  • Domain ~₹1,000/year
  • Workers Paid $5/month (after the bot scan)
  • 1 warm instance ~₹850/month
  • Gateway fee ~2% + GST per sale

Ads, with a stop-loss

  • Start ₹200–300/day, one channel at a time
  • First sale expected after a few hundred ₹
  • Stop if ₹1,500 spent and no payment
  • Keep CPA under your margin incl. GST

House rules

For you and the agent, on every project.

No secrets in chatDashboards and Secret Manager only.
No personal IDsNot in the repo, memory or pages.
PRs onlyMerging to main deploys to production.
Only real claimsNo invented reviews or features.
Pay-per-useNo flat fee until revenue covers it.
Admin stays hiddenNever linked from the site or robots.
“A small team”No personal names on the site.
